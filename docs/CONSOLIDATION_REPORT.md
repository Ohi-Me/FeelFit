## 11. Remaining Manual Steps

**For web development:** NONE. Run `scripts/dev.sh` or `cd frontend && npm run dev`.

**For mobile development (one-time setup per machine):**
1. **Android Studio:** Install Android Studio + Android SDK. Then `npx cap open android` → Run ▶.
2. **iOS (macOS only):** Install Xcode 15+ + CocoaPods. Then `cd ios/App && pod install && npx cap open ios` → Run ▶.

**For mobile development (every code change):**
1. Edit code in `frontend/`
2. `BUILD_TARGET=mobile npm run build && npx cap sync`
3. Re-run in Android Studio / Xcode

**Or use the one-shot helper:**
```bash
scripts/build-mobile.sh android   # build + sync + open Android Studio
scripts/build-mobile.sh ios       # build + sync + open Xcode
```
